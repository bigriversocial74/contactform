# Microgifter Creator Campaign UI Prompt Library

## Master visual prompt

Design a high-fidelity desktop web application interface for Microgifter, an AI-assisted social gifting, merchant CRM, campaign, rewards, and automated commerce platform.

Match the existing Microgifter visual language: a light professional operating-system-style interface with white and soft-gray surfaces, strong black typography, restrained blue accents, rounded cards, subtle borders, gentle shadows, clean spacing, and polished Apple/Stripe-inspired SaaS design.

Use a full-width application layout with the existing Microgifter-style merchant or creator sidebar on the left, a compact account header across the top, and a large working canvas. The interface should feel sophisticated, commercially usable, and production-ready rather than like a generic dashboard template.

Use realistic local merchant products, creator profile photos, campaign artwork, social content previews, CRM contact information, Microgift activity, commissions, earnings, and attribution metrics.

Avoid dark mode, excessive gradients, cryptocurrency visuals, stock-trading charts, cartoon graphics, oversized empty hero sections, and heavy blue backgrounds.

Desktop viewport, approximately 1440 pixels wide. Crisp high-fidelity product design mockup.

The generated global header and footer are not authoritative. Prioritize the main content area, information architecture, spacing, cards, tables, controls, and workflow clarity.

## 1. Merchant Creator Campaign overview

Using the established Microgifter design system, create a high-fidelity desktop screen titled “Creator Campaigns.”

Show the existing Microgifter merchant sidebar with Campaigns selected.

The main workspace should include:

- Header with “Creator Campaigns,” short descriptive text, Create Campaign button, and date-range filter
- Summary cards for Active Campaigns, Approved Creators, Pending Applications, Content Awaiting Review, Attributed Revenue, Pending Earnings, and Budget Remaining
- Campaign health panel showing agreements awaiting acceptance, overdue deliverables, budget warnings, and attribution conflicts
- Recent campaign activity feed
- Active campaign cards with campaign image, objective, status, creator count, deliverables, attributed revenue, creator cost, conversion rate, and budget progress
- Top-performing creators table with creator photo, campaigns, signups, revenue, earnings, and conversion rate

Use realistic local hospitality, restaurant, music, fitness, and event campaigns.

## 2. Campaign Builder — Compensation

Using the established Microgifter design system, create a high-fidelity desktop multi-step “Create Creator Campaign” builder.

Use the Microgifter merchant sidebar and account header.

The builder should show a ten-step navigation:

1. Campaign Details
2. Products
3. Creator Eligibility
4. Deliverables
5. Compensation
6. Attribution
7. Budget
8. Content Rights
9. Terms
10. Review

Display Step 5, Compensation, as the active step.

The main form should include:

- Fixed campaign payment
- Payment per deliverable
- Percentage commission per sale
- Qualified signup payment
- Performance bonus
- Add Compensation Rule button
- Hold period
- Per-creator limit
- Campaign-wide cap
- Reversal conditions
- Rules may stack toggle

Include a sticky right-side campaign summary showing selected products, creators, deliverables, compensation summary, estimated maximum liability, campaign dates, and completion checklist.

Use a dense, polished form layout with clear labels and no oversized empty areas.

- The same typography hierarchy
- The same card radius and border treatment
- The same table row density
- The same campaign status colors
- The same creator identity treatment
- The same earnings and attribution terminology
- The same light Microgifter workspace styling
- The repository’s real shared shell during implementation
