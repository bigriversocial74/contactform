# Microgifter Creator Campaign UI Mockups

## Approved visual direction

The mockups preserve the approved main-content direction for Microgifter's creator campaign system.

Design characteristics:

- Light professional interface
- White and soft-gray surfaces
- Strong black typography
- Restrained blue accents
- Rounded cards and panels
- Subtle borders and shadows
- Dense but readable operational layouts
- Existing Microgifter-style SaaS presentation
- Realistic products, creators, campaigns, CRM activity, earnings, and attribution data

The generated global header and footer are not authoritative. The main content composition is the reference.

## Implementation note

When production UI work begins, use the repository's actual shared header, footer, sidebar, typography, spacing variables, buttons, cards, form controls, and responsive behavior. The mockups guide the main workspace layout rather than replacing the existing shell.
