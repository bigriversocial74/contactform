# Participant Quest Experience v1 Release Boundary

This section provides the complete Microgifter-native participant Loyalty Quest journey from enrollment through verification, merchant review, reward issuance, and progress history.

It does not replace Microgifter reward, claim, redemption, identity, or merchant ownership authority. It uses the existing campaign, wallet, PPPM, CRM, permission, audit, and migration systems.

SQL required:

- `database/loyalty_quest_participant_experience_v1.sql`
- `database/shared_microgifter_identity_v1.sql` remains required from the prior identity section and is now registered in the canonical migration manifest.
